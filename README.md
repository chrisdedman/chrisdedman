I'm a software engineer focused on systems programming, developer tooling, and open-source software. Professionally, I work as a full-stack engineer developing a large-scale content management system (CMS) using TypeScript and Rust. Outside of work, I build operating systems and developer tools in C, C++, Rust, and Python. I'm also exploring event-driven architecture and asynchronous systems through my contributions to [matrix.py](https://github.com/Code-Society-Lab/matrixpy).
